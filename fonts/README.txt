Optional fonts (recommended for the best Arabic look)
-----------------------------------------------------
Download the free (OFL) fonts "Cairo" or "Tajawal" from Google Fonts and copy the
.ttf files into this folder. The app loads them automatically at start-up.
Order of preference: Cairo > Tajawal > IBM Plex Sans Arabic > Noto Sans Arabic > Segoe UI > Tahoma.
Without any file here, Windows' Segoe UI is used.
