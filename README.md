# منظّم الفريق (نسخة أولية)

تطبيق Windows محلي لإدارة مهام فريق من 2 إلى 10 أفراد، بواجهة عربية RTL.

## التشغيل
1. ثبّت Python 3.11 أو أحدث على Windows.
2. افتح المجلد في Terminal.
3. نفّذ: `py -m venv .venv`
4. نفّذ: `.venv\\Scripts\\activate`
5. نفّذ: `py -m pip install -r requirements.txt`
6. نفّذ: `py main.py`

البيانات تُحفظ في `%LOCALAPPDATA%\\MounazzemAlFariq\\team_tasks.sqlite3`.

## الموجود في النسخة الأولية
- إدارة الأفراد، بحد أقصى 10 أفراد نشطين.
- إضافة المهام وتعديلها وتغيير حالتها وأرشفتها أو حذفها نهائيًا.
- البحث بالعنوان والتفاصيل واسم المسؤول.
- أولوية من 1 إلى 10 وتاريخ ووقت وتذكير قبل الموعد.
- تكرار يومي أو أسبوعي عند إنشاء المهمة.
- نسخ رسالة منسقة إلى الحافظة لإرسالها عبر واتساب.
- تصدير PDF وWord وExcel حسب الفترة والفرد.
- تنبيهات منطقة إشعارات Windows عند قرب الموعد أو تأخر المهمة.
- واجهة تخطيط يومي وأسبوعي وشهري مع تنقل سريع بين الفترات وتصفية حسب الفرد.
- مؤشرات مرئية لإجمالي المهام والمفتوحة والمنجزة والمتأخرة، ومخطط توزيع المهام حسب ساعات اليوم أو أيام الفترة.
- جدول التخطيط يميز المهام المتأخرة والمنجزة بالألوان، ويسمح بفتح المهمة للتعديل بالنقر المزدوج.

## ملاحظات مهمة قبل الاعتماد
- هذه نسخة أولية قابلة للاختبار وليست إصدارًا نهائيًا. اختبرها على نسخة من بياناتك أولًا.
- يلزم أن يبقى التطبيق يعمل في منطقة الإشعارات لتعمل التنبيهات؛ لن تعمل إذا أُغلق التطبيق بالكامل أو كان الكمبيوتر مطفأً.
- دعم تشكيل العربية في PDF يعتمد على الخط المتوفر؛ يجب اختبار شكل الحروف واتجاهها على جهاز Windows المستهدف قبل اعتماد التقارير رسميًا.
- التكرار ينشئ نسخًا مستقلة من المهمة حتى التاريخ المحدد، ولا يغيّر المهام المنشأة سابقًا عند تعديل القالب.
- يجب إجراء نسخ احتياطي دوري لملف قاعدة البيانات.

## الاختبارات
يمكن تشغيل اختبارات قاعدة البيانات باستخدام: `py -m unittest test_database.py`.

## المظهر والواجهة (تحديث التصميم)
- ملفات جديدة: `theme.py` (الألوان والخطوط والأيقونات وأنماط QSS) و`widgets.py` (المكوّنات المتحركة).
- مظهر فاتح وداكن بزر في الترويسة، ويُحفظ اختيارك تلقائيًا.
- ترويسة متدرجة بإضاءة متحركة، وتنقل بين التبويبات بمؤشر ينزلق وانتقال تلاشٍ بين الصفحات.
- أزرار بتأثيرات تمرير وضغط وتوهج، وبطاقات ظلال ناعمة، وبطاقات مؤشرات بتدرجات وعدّاد متحرك.
- مخطط أعمدة متدرج متحرك مع فقاعة عند التمرير، ومخطط دائري لحالة المهام.
- جداول بتمييز الصف عند التمرير، وشارات حالة ملونة، وشريط أولوية، وصور رمزية للأفراد.
- إشعارات منزلقة (Toast) بدل رسائل التأكيد، ونافذة اختيار حالة بنقرة واحدة.
- للحصول على أفضل شكل للعربية ضع خط Cairo أو Tajawal (ملفات .ttf) داخل المجلد `fonts/`.

## الإصدار الموسّع - الميزات الجديدة
**صفحات جديدة** (التنقل: Ctrl+1 … Ctrl+9)
- **الرئيسية:** مؤشرات اليوم والمتأخرات ونسبة الإنجاز، جدول اليوم، عبء العمل لكل فرد، مخطط الإنجاز مقابل المستحق، والمهام القادمة، وزر «نسخ ملخص اليوم» لواتساب.
- **اللوحة (كانبان):** أعمدة الحالات؛ اسحب البطاقة لتغيير حالتها، مع تصفية حسب الفرد.
- **التقويم:** شبكة شهرية بالمهام الملوّنة؛ نقرة لاختيار اليوم ونقرتان لإضافة مهمة فيه.
- **النشاط:** سجل بكل ما جرى (إنشاء/تعديل/أرشفة/استعادة/حذف) مع الوقت النسبي.
- **الإعدادات:** المظهر الفاتح/الداكن + 4 ألوان رئيسية، بداية الأسبوع وأيام العطلة وساعات العمل والتذكير الافتراضي، النسخ الاحتياطي والاستعادة، وتصدير CSV.

**تحسينات المهام**
- فئات للمهام، وقائمة خطوات (Checklist) مع شريط تقدم في الجدول.
- تصفية حسب الحالة/المتأخرة/الفرد/الفئة وترتيب بأربعة معايير.
- قائمة بالزر الأيمن، ونسخ المهمة، وزر «إنجاز» سريع.
- تنبيه عند تعارض موعد المهمة مع مهمة أخرى للفرد نفسه.
- تكرار يومي/أيام العمل/أسبوعي/شهري.
- تفعيل الأفراد المعطّلين من جديد.

**أدوات عامة**
- لوحة الأوامر `Ctrl+K`، واختصارات: `Ctrl+N` مهمة جديدة، `Ctrl+F` بحث، `Ctrl+D` تبديل المظهر، `F5` تحديث.
- نسخ احتياطي تلقائي عند الإغلاق (آخر 7 نسخ في مجلد backups) ونسخ/استعادة يدويان.
- ترقية قاعدة البيانات القديمة تلقائيًا دون فقدان بيانات.

الاختبارات: `python -m unittest test_database.py test_logic.py`
